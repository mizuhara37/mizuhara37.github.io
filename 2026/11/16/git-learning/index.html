总之Git就是会记录项目在不同时间点的版本

最基础的Git操作

其流程为 Working Directory –git add–> Staging Area –git commit–>Local Repository

分支管理

当想修改程序又怕程序出错，就创建一个新分支

main主分支,保存稳定的版本
feature功能分支,用于开发新功能
ABCDE不同的提交记录

所以可以在feature上自由修改代码,而不影响main

分支冲突

假设：

  • main 修改了 analysis.py 的第一行
  • feature 也修改了同一行
  • 你尝试合并两个分支
    Git 可能无法自动判断应该保留哪一个版本

这就叫做 Merge Conflict（合并冲突）

含义：

  • <<<<<<< HEAD：当前分支的内容
  • =======：分隔线
  • >>>>>>> feature：待合并分支的内容
    你需要手动编辑文件，决定最终保留什么，然后

git clone

完整下载项目途径,git会自动：

  1. 下载项目文件。
